プライバシーポリシー

最終更新：2026年11月19日

  • このツールは運営者本人だけが、自分の Google アカウントで YouTube Data API・YouTube Analytics API・YouTube Reporting API を使うためのものです。
  • 取得するのは運営者自身のチャンネルの情報（動画・再生リスト・コメント・分析の数字）だけで、運営者のパソコンの中だけに保存します。
  • 取得した情報を第三者に提供・販売・共有しません。広告にも使いません。
  • Google API から受け取った情報の使い方は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。
  • 許可はいつでも Google アカウントの「サードパーティ製のアプリとサービス」から取り消せます。
  • YouTube の利用規約（https://www.youtube.com/t/terms）と Google のプライバシーポリシー（https://policies.google.com/privacy）も適用されます。

Privacy Policy (English)

  • This tool is used only by its operator, with the operator's own Google account, to access the YouTube Data API, YouTube Analytics API and YouTube Reporting API.
  • It reads only the operator's own channel data (videos, playlists, comments, analytics) and stores it only on the operator's own computer.
  • No data is sold, shared with, or transferred to any third party, or used for advertising.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Access can be revoked at any time from the Google Account "Third-party apps & services" page.
  • The YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy) also apply.
